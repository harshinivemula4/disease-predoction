# Disease Prediction System

##  Description
A machine learning-based disease prediction system that analyzes user symptoms and predicts possible diseases using trained models.

## Features
- User symptom input
- Disease prediction using ML models
- Frontend interface for easy interaction

##  Tech Stack
- Python
- Machine Learning
- MERN Stack (Frontend)

## How to Run

### Backend (ML model)
Run Python file to start prediction system  

### Frontend
cd frontend  
npm install  
npm start
